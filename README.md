# Komentář k zákonu č. 20/1987 Sb., o státní památkové péči

Odborný komentář k **zákonu č. 20/1987 Sb., o státní památkové péči** — mnohokrát novelizovanému předpisu ochrany památkového fondu: prohlašování kulturních památek, národní kulturní památky, rezervace a zóny, povinnosti vlastníků a závazná stanoviska, archeologické výzkumy a nálezy, restaurátorské licence a role Národního památkového ústavu.

Konsolidované znění: dokument e-Sbírky `SB-1987-00020_2025-07-01`.
